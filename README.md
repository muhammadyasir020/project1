## Project Proposal: Tourism Management System

The Islamia University of Bahawalpur Department of Information Technology

Submitted By: Muhammad Yasir Roll Number: F23BINFT1E02053 Semester: 7th — Section 2E Degree: BS Information Technology (BS IT)

### 1\. Introduction

The Tourism Management System is a web-based application that helps users explore tourist places, hotels, and travel facilities through one website.

### 2\. Problem Statement

Tourists often face difficulty finding information about tourist places, hotels, and transportation in one place. This system provides all these details through a simple website.

### 3\. Objectives

* Provide information about tourist destinations.

* Display hotel and travel facilities.

* Search places by city or category.

* Allow users to save favorite places.

### 4\. Scope

Users can search for tourist places, view pictures and descriptions, and save favorites. The admin can add, update, and delete destination information.

### 5\. Methodology

The project will follow the Waterfall Model: requirements, design, development, testing, and implementation.

### 6\. Tools and Technologies

* Frontend: HTML, CSS, JavaScript, Bootstrap

* Backend: PHP

* Database: MySQL

* Server: XAMPP

### 7\. Expected Outcome

A simple and user-friendly website that helps tourists find destinations and travel information easily.

### 8\. Conclusion

The Tourism Management System will organize tourist information in one place. It is suitable for a BS IT final-year project and can be developed using PHP, MySQL, and XAMPP.
