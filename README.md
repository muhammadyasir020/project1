# Project Proposal: Tourism Management System

University: The Islamia University of Bahawalpur Name: Muhammad Yasir Roll No: F23BINFT1E02053 Department: BS IT, 7th Semester, Section 2E

### 1\. Introduction

A website that provides information about famous tourist places.

### 2\. Problem Statement

People face difficulty finding information about tourist places in one place.

### 3\. Objectives

* Show tourist places and pictures.

* Provide basic information about destinations.

* Help users search places by city.

### 4\. Scope

Users can view tourist places, and the admin can manage their information.

### 5\. Tools

HTML, CSS, JavaScript, PHP, MySQL, and XAMPP.

### 6\. Conclusion

This website will help people find tourist information easily and is suitable for a BS IT final-year project.
